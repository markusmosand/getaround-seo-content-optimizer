# AI Writing Detection Avoidance

Phrases and patterns to avoid that signal AI-generated content, plus natural alternatives.

**Note:** These patterns apply to ALL languages. Norwegian and French equivalents of these phrases are equally problematic.

## Em Dashes
AI content overuses em dashes. Use commas, colons, or split into sentences instead.

❌ "Car sharing — the sustainable choice — is growing fast"
✅ "Car sharing is growing fast. It's the sustainable choice for urban mobility."

## Overused Transition Words
These phrases are AI tells when used frequently:

| Avoid | Use Instead |
|-------|-------------|
| "Furthermore,..." | "Also,..." / "Plus,..." |
| "Moreover,..." | "What's more,..." / "On top of that,..." |
| "However,..." (at start) | "But..." / "That said,..." |
| "In conclusion,..." | "The takeaway?" / "Here's what matters:" |
| "In summary,..." | "Quick summary:" / "So what does this mean?" |
| "As such,..." | "So,..." / "This means..." |
| "It is important to note..." | "Note that..." / (just state it) |

## Filler Phrases
Remove entirely or replace:

| Avoid | Replace With |
|-------|--------------|
| "It's worth noting that..." | (state directly) |
| "It's important to understand..." | (state directly) |
| "It should be mentioned..." | (state directly) |
| "In today's fast-paced world..." | (delete, get to point) |
| "In the realm of..." | "In..." / "For..." |
| "When it comes to..." | "For..." / "With..." |
| "At the end of the day,..." | "Ultimately,..." / (state directly) |
| "The fact of the matter is..." | (state directly) |
| "This begs the question..." | "This raises the question:" |

## Hollow Adjectives
These add length without meaning:

| Avoid | Replace With |
|-------|--------------|
| "innovative" | (describe what's actually new) |
| "cutting-edge" | (describe the specific technology) |
| "revolutionary" | (describe the actual impact) |
| "seamless" | (describe how it works) |
| "robust" | (describe what it handles) |
| "comprehensive" | (list what's included) |
| "state-of-the-art" | (describe the specific features) |

## Opener Tells
AI loves to start with these:

❌ "In today's digital landscape..."
❌ "In an era of..."
❌ "As we navigate..."
❌ "In the ever-evolving world of..."
❌ "Have you ever wondered..."
❌ "Let's delve into..."
❌ "Let's explore..."
❌ "At its core,..."

✅ Start with a specific fact, question, or scene
✅ Start with the reader's problem
✅ Start with a surprising statistic

## Structure Tells
AI often creates:
- Perfect 3-bullet patterns repeatedly
- Exactly 5 items in every list
- Headers that all follow the same formula
- Paragraphs all the same length

**Fix:** Vary your structure. Mix short and long paragraphs. Have lists of 4, 7, or 11 items sometimes.

## Natural Alternatives by Category

### Instead of Introducing Topics
| AI Phrase | Human Alternative |
|-----------|------------------|
| "Let's delve into..." | "Here's what matters:" |
| "Let's explore..." | "Here's the breakdown:" |
| "We'll discuss..." | (just start discussing) |
| "In this article, we will..." | "You'll learn:" |

### Instead of Concluding
| AI Phrase | Human Alternative |
|-----------|------------------|
| "In conclusion,..." | "The takeaway?" |
| "To sum up,..." | "Quick summary:" |
| "In summary,..." | "So what does this mean?" |
| "All things considered,..." | "Bottom line:" |

### Instead of Transitioning
| AI Phrase | Human Alternative |
|-----------|------------------|
| "Furthermore,..." | "Plus,..." / "Also,..." |
| "Additionally,..." | "And..." / "There's more:" |
| "Moving forward,..." | "Next,..." |
| "With that being said,..." | "That said,..." / "But..." |

### Instead of Emphasizing
| AI Phrase | Human Alternative |
|-----------|------------------|
| "It is crucial to..." | "Make sure to..." |
| "It is essential that..." | "You need to..." |
| "It is imperative to..." | "Always..." / "Don't skip..." |

## Quick Self-Check

Before publishing, scan for:
1. Em dash overuse (more than 1-2 per article)
2. "Furthermore/Moreover/However" at paragraph starts
3. Hollow adjectives without specifics
4. "In today's..." or "In an era of..." openers
5. Perfect pattern repetition (all 3s or all 5s)
6. Sentences starting with "It is..."
7. "Delve," "explore," "navigate" as verbs

If you find 3+ of these patterns, revise for more natural voice.

## Norwegian AI Tells

| Unngå | Bruk heller |
|-------|-------------|
| "Når det er sagt,..." | "Men..." / "Samtidig..." |
| "Det er verdt å merke seg at..." | (si det direkte) |
| "I dagens samfunn..." | (gå rett til poenget) |
| "La oss dykke inn i..." | "Her er..." / "Slik gjør du:" |
| "Avslutningsvis,..." | "Oppsummert:" / "Det viktigste?" |
| "Videre,..." (overbrukt) | "Dessuten..." / "I tillegg..." |
| "Det er viktig å forstå at..." | (si det direkte) |

**Naturlige norske alternativer:**
- "Her er det viktigste:"
- "Poenget er:"
- "Men her er greia:"
- "Kort sagt:"
- "Så hva betyr dette?"

## French AI Tells

| Éviter | Utiliser plutôt |
|--------|-----------------|
| "Cela étant dit,..." | "Mais..." / "Cependant,..." |
| "Il convient de noter que..." | (dire directement) |
| "Dans le paysage actuel..." | (aller droit au but) |
| "Plongeons dans..." | "Voici..." / "Comment faire :" |
| "En conclusion,..." | "En bref :" / "L'essentiel ?" |
| "De plus,..." (surutilisé) | "Aussi..." / "Par ailleurs..." |
| "Il est important de comprendre..." | (dire directement) |

**Alternatives françaises naturelles :**
- "Voici l'essentiel :"
- "Le point clé ?"
- "Mais voici le point important :"
- "En résumé :"
- "Qu'est-ce que cela signifie ?"
