# Owner Content Principles (Universal)

Universal guidelines for owner/utleier content. Applies to ALL markets.

---

## Information Hierarchy Rule

**ANSWER FIRST, EXPLAIN AFTER.**

This is the most critical principle for owner content. Readers arrive with a specific question - answer it immediately.

### Introduction Requirements (4-5 lines max)

Every owner article introduction must follow this sequence:

1. **Answer the main question FIRST** - Lead with the direct answer
2. **Safety/trust guarantee SECOND** - Address insurance/protection immediately
3. **How it works THIRD** - Brief explanation of process

### Example Structure

**Good:**
> Du kan tjene mellom 3 000 og 15 000 kroner i måneden på å leie ut bilen din, avhengig av biltype og beliggenhet. Bilen er fullt forsikret under hver utleie gjennom If. Leietakere booker via Getaround-appen, og med Connect-teknologi låser de opp bilen selv – du trenger ikke være til stede.

**Bad:**
> I en tid der deleøkonomi vokser, har mange nordmenn oppdaget mulighetene ved å dele bilen sin. Getaround er en plattform som kobler bileiere med folk som trenger bil. La oss se på hvordan dette fungerer...

### Anti-Patterns (All Markets)

| Pattern | Problem | Fix |
|---------|---------|-----|
| Starting with specific example | Reader unsure if applies to them | Start with general answer, then examples |
| Historical/context intro | Delays the answer | Skip backstory, lead with answer |
| "In this article..." openings | Wastes reader time | State the answer, not what you'll cover |
| Positioning for ONE car type | Excludes most readers | Cover multiple car types with ranges |
| Burying answer below fold | Mobile users miss it | Answer in first 2-3 sentences |

## Headline Strategy (Hybrid for SEO + AEO)

Balance search engine optimization with Answer Engine Optimization using a hybrid headline approach.

### H2: Question Format (AEO-Optimized)

Use questions for main section headers (H2). This:
- Matches natural search queries
- Improves featured snippet eligibility
- Helps AI overviews cite your content
- Creates clear navigation

**Examples:**
- "Hvor mye kan du tjene på å leie ut bilen?"
- "Combien pouvez-vous gagner avec votre voiture ?"
- "Hvordan fungerer forsikringen?"
- "Comment fonctionne l'assurance ?"

### H3: Statements with Numbers OK

Use statement-style H3 headers for subsections. These:
- Support internal navigation
- Can include compelling data
- Improve click-through on in-page links

**Examples:**
- "Tesla Model 3: 8 000–15 000 kr/mnd"
- "Paris : jusqu'à 800 €/mois"
- "5 steg for å komme i gang"

### Critical Rule

**First sentence after H2 = direct answer with data.**

Don't introduce, don't context-set - answer immediately after the question header.

## Reader-First Principle

Before writing any owner content, answer these three questions:

### 1. What Situation is the Reader In?

| Situation | Content Approach |
|-----------|------------------|
| Considering if worth it | Lead with income ranges, low barrier |
| Ready to start | Focus on step-by-step, quick wins |
| Already listing, wants optimization | Advanced tips, pricing strategy |
| Concerned about risks | Lead with insurance, damage handling |

### 2. What Did They Search?

Match the search query directly:

| Query Type | Reader Expectation |
|------------|-------------------|
| "tjene penger på bil" | Income amounts first |
| "lei ut bil forsikring" | Insurance details first |
| "smartprising Getaround" | Pricing tool explanation |
| "Connect installation" | Technical process info |

### 3. What Are They Worried About?

Address concerns proactively:

| Common Concern | How to Address |
|----------------|----------------|
| Damage to car | Insurance coverage, photo documentation |
| Strangers using car | Verification process, reviews |
| Tax implications | Link to official sources, disclaimers |
| Too complicated | Emphasize simplicity, step count |
| Not worth it financially | Concrete income examples |

## External Reference Guidelines

Different data types require different approaches to maintain accuracy and trust.

### Reference Matrix

| Data Type | Volatility | Approach | Example |
|-----------|------------|----------|---------|
| Tax rates/rules | High (changes annually) | **Refer to source** - don't cite specific numbers | "For gjeldende skatteregler, se Skatteetaten.no" |
| Tax thresholds | Medium (periodic changes) | **Cite + caveat** - include disclaimer | "Grensen er p.t. 10 000 kr (sjekk Skatteetaten for oppdatert info)" |
| Internal data | Low (we control it) | **Cite directly** with ranges | "Utleiere tjener typisk 3 000–15 000 kr/mnd" |
| Insurance specifics | Medium | **Refer to page** - details may change | "Se fullstendige forsikringsvilkår på getaround.com" |
| Process steps | Low | **Cite directly** - we own the process | "1. Last ned appen 2. Registrer bilen..." |

### Why This Matters

- **Volatile data ages fast** - Citing "skattesats 22%" becomes wrong when rate changes
- **Referring maintains trust** - Reader knows to check official source
- **Internal data is safe** - We control and update it
- **Disclaimers protect credibility** - Shows awareness of change

## Technical Term Handling

Define ALL technical terms immediately at first use. Never assume reader knows Getaround terminology.

### Format

**[Term] ([definition in parentheses])**

### Examples

- "Getaround Connect (teknologi som lar leietaker låse opp bilen via appen)"
- "SmartPrising (automatisk prisjustering basert på etterspørsel)"
- "Instant booking (leietaker kan booke uten at du må godkjenne)"
- "Native Connect (Smartcar-integrasjon for Tesla uten hardware)"

### Term Introduction Checklist

When introducing a Getaround term:
1. Name the term
2. Define it in plain language
3. Explain benefit to owner
4. Use consistently thereafter

## Article Structure Template (Owner Guides)

Standard structure for comprehensive owner content:

### 1. Title
- Include search intent keyword
- Include number if applicable
- Format: "[Topic]: [Benefit/Result]" or "Hvordan [action] – [outcome]"

### 2. Introduction (4-5 lines)
- Answer → Trust → Function sequence
- Cover multiple car types in income example
- Mention insurance immediately

### 3. What Can You Earn?
- Multiple car types with ranges
- Geographic variations
- Factors affecting income
- Use table format for clarity

### 4. How It Works
- Product explanation (Connect, key handover)
- Correct terminology (see glossary)
- Step-by-step process
- Photo examples if helpful

### 5. Safety and Insurance
- Coverage details
- What's included
- What's not covered
- Damage handling process

### 6. Getting Started (5 steps max)
- Clear numbered steps
- Time estimate for each
- Required documents/info
- What to expect

### 7. Tips for Best Results
- Pricing optimization
- Availability strategies
- Photo tips
- Response time importance

### 8. FAQ (5-10 questions)
- Common concerns as questions
- Brief, direct answers (50-100 words)
- Include long-tail keywords

### 9. CTA
- Clear next action
- Link to registration/listing
- Medium strength (not pushy)

## Quality Checklist (Owner Content)

Before publishing any owner article:

### Information Hierarchy
- [ ] Main question answered in first 2-3 sentences
- [ ] Insurance/trust mentioned in intro
- [ ] Multiple car types covered (not just one example)
- [ ] Income ranges provided (not single numbers)

### Headlines
- [ ] H2s are questions (AEO-optimized)
- [ ] H3s support navigation
- [ ] First sentence after H2 = direct answer

### Reader-First
- [ ] Reader's situation identified
- [ ] Search query matched
- [ ] Concerns addressed proactively

### Technical Terms
- [ ] All Getaround terms defined at first use
- [ ] Consistent terminology throughout
- [ ] Matches official glossary

### References
- [ ] Volatile data references source (not cited)
- [ ] Internal data cited with ranges
- [ ] Disclaimers on changing information

### Structure
- [ ] Follows standard template
- [ ] 5 steps max for getting started
- [ ] FAQ section included
- [ ] Appropriate CTA
