## Common Mistakes to Avoid

| Mistake | Why it is wrong | Correct approach |
|---------|-----------------|------------------|
| Claiming RV/Motorhome available in France | Norway exclusive | Check segment table above |
| Claiming Native Connect in France | Norway exclusive (Smartcar API) | Only mention for Norway content |
| Claiming long-term rental (30-180 days) in France | Norway exclusive | Do not mention for France |
| Citing specific income number (e.g., "earn 15,000 kr") | Misleading without context | Always use ranges with location and vehicle type qualifiers |
| Saying "Assurance tous risques incluse" without clarification | Implies single coverage level | Clarify: 3 protection levels (Minimum, Plus, Premium) |
| Mentioning Entrepreneurs program for Norway | Not verified for NO market | Only confirmed for France (3 tiers: Entrepreneur, Professionnel, Enterprise) |
| Using If as insurance partner for France | If is Norway only | France uses AXA |
| Using AXA as insurance partner for Norway | AXA is France only | Norway uses If |
| Claiming specific tax rates or thresholds | Tax data is volatile | Refer to Skatteetaten.no (NO) or impots.gouv.fr (FR) |
| Stating regulatory deadlines as fact | Regulations change frequently | Add caveat: "check [source] for current rules" |
