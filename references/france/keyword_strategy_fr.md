# French Keyword Strategy - Getaround

Strategic keyword framework for Getaround France blog content optimization.

---

## Executive Summary

French search behavior is dominated by **B2B/professional queries** and **regulatory compliance** content. Unlike Norway where consumer activities drive traffic, France's top performers address professional vehicle usage, fiscal optimization, and regulatory requirements (ZFE, Crit'Air, TVS).

**Key Insight:** Professional/B2B keywords generated 21,519 clicks/month from just 3 articles - 68% of top 5 traffic.

## Keyword Integration Rules

### Title Tags (H1)
- Include primary keyword
- Add year for regulatory/professional content
- Keep under 60 characters
- Example: "Déplacement professionnel : guide complet 2025"

### Meta Descriptions
- Include primary keyword naturally
- Add call-to-action
- 150-160 characters
- Example: "Tout savoir sur les frais de déplacement professionnel en 2025. Barème kilométrique, remboursement, optimisation fiscale. Guide complet."

### Headers (H2/H3)
- Include secondary keywords
- Use question format for AEO
- Logical hierarchy
- Example H2: "Comment calculer l'indemnité kilométrique en 2025 ?"

### Body Content
- Natural keyword density (1-2%)
- Use variations and synonyms
- Include related entities (URSSAF, Code du travail, etc.)
- Semantic richness over keyword stuffing
