# CTA Framework for Getaround Content

Comprehensive guidelines for creating high-converting calls-to-action in car-sharing content.

---

## Part 1: CTA Psychology Principles

### The Four Conversion Triggers

Every effective CTA leverages one or more psychological triggers:

**1. Clarity**
- Eliminate decision fatigue with crystal-clear direction
- User should know exactly what happens when they click
- Specific > vague: "Find cars in Oslo" beats "Learn more"
- Action verb + outcome: "Book your weekend car" not "Submit"

**2. Urgency**
- Time-sensitive language creates immediate action
- Use sparingly and authentically (fake urgency backfires)
- Works best for: seasonal content, limited availability, owner recruitment
- Examples: "Book now for summer", "Weekend cars fill fast"

**3. Value Proposition**
- Focus on benefits, not features
- Answer: "What's in it for me?"
- Quantify when possible: "Save up to 40%", "Earn 8000 kr/month"
- Emotional benefits: freedom, convenience, peace of mind

**4. Exclusivity/FOMO**
- Fear of missing out drives action
- Works best for: owner content, premium features, new launches
- Use with caution in renter content (can feel pushy)
- Examples: "Join 8000+ owners", "Get Connect access"

### Key Statistics (2025-2026)
- Personalized CTAs perform 42% better than generic ones
- Button-based CTAs increase CTR by ~30% vs text links
- CTAs after intro content convert 17% better than above-fold placement
- Optimal CTA length: 5-7 words

## Part 2: CTA Strength Matrix

### Intent-Based CTA Strength

| Search Intent | CTA Strength | Placement | Example |
|---------------|--------------|-----------|---------|
| Informational | Soft | End only | "Utforsk flere aktiviteter" |
| Commercial Investigation | Medium | Middle + End | "Se tilgjengelige biler" |
| Transactional | Strong | Throughout | "Book din leiebil nå" |
| Navigational | Direct | Above fold OK | "Finn biler i Oslo" |

### Audience-Based CTA Strength

| Audience | Default Strength | Trigger Focus | Example |
|----------|------------------|---------------|---------|
| Renter (activity content) | Soft | Value | "Plan din neste tur" |
| Renter (use-case content) | Medium | Value + Clarity | "Finn bil til bryllupet" |
| Renter (comparison/pricing) | Strong | Value + Urgency | "Sammenlign priser nå" |
| Owner (awareness) | Medium | Value | "Se hvor mye du kan tjene" |
| Owner (consideration) | Strong | Value + Social proof | "Bli en av 8000+ utleiere" |
| Owner (decision) | Strong | Urgency + Clarity | "Registrer bilen din i dag" |

### Content Type CTA Guide

**Activity Guides / Listicles (Renter)**
- Strength: Soft
- Placement: End only
- Trigger: Value
- Template: "Klar for [aktivitet]? Finn din leiebil på Getaround."

**Use-Case Articles (Renter)**
- Strength: Medium
- Placement: After use-case description + End
- Trigger: Value + Clarity
- Template: "Trenger du bil til [bruksområde]? Se tilgjengelige biler i [by]."

**How-To Guides (Owner)**
- Strength: Strong
- Placement: After benefits section + End
- Trigger: Value + Social proof
- Template: "Klar til å tjene på bilen din? Registrer deg på Getaround i dag."

**City Guides**
- Strength: Soft
- Placement: End only (within "Getting Around" section)
- Trigger: Value
- Template: "Utforsk [by] med leiebil – finn biler i nærheten."

**Comparison Articles**
- Strength: Medium-Strong
- Placement: After comparison table + End
- Trigger: Value + Clarity
- Template: "Se hvordan Getaround sammenligner seg – finn biler nå."

## Part 4: CTA Placement Rules

### Strategic Placement Guidelines

**Never Place CTAs:**
- Above the fold (17% conversion decrease)
- Before explaining the value proposition
- In the middle of a key explanation
- Multiple CTAs in same visible area

**Optimal Placement Patterns:**

**Pattern 1: End-Only (Default for informational content)**
```
[Intro with hook]
[Value-driven content sections]
[FAQ section]
[Single CTA at end]
```

**Pattern 2: Middle + End (For longer content, 2000+ words)**
```
[Intro with hook]
[Content sections 1-3]
[Contextual soft CTA - relates to previous section]
[Content sections 4-6]
[FAQ section]
[Primary CTA at end]
```

**Pattern 3: Benefits + End (For owner content)**
```
[Intro with pain point]
[Solution/benefits section]
[CTA after benefits] ← "Klar til å begynne?"
[How-it-works section]
[Data/proof section]
[FAQ section]
[Primary CTA at end]
```

### CTA Integration (Not Interruption)

**Good: Contextual CTA**
```markdown
## Planlegg turen med leiebil

For å besøke alle disse attraksjonene på én dag, er leiebil praktisk.
Med biler tilgjengelig i alle bydeler i Oslo kan du enkelt kjøre mellom
destinasjonene.

**Finn biler i Oslo på Getaround →**
```

**Bad: Interruptive CTA**
```markdown
## De beste attraksjonene

**BOOK NÅ OG SPAR 20%!**

Vikingskipshuset er et populært museum...
```

## Part 6: CTA Copywriting Formulas

### Formula 1: Action + Benefit
```
[Action verb] + [what user gets]

Examples:
- "Finn din perfekte leiebil" (Find your perfect rental car)
- "Spar opptil 40% på billeie" (Save up to 40% on car rental)
- "Tjen passiv inntekt på bilen" (Earn passive income from your car)
```

### Formula 2: First-Person POV
```
"Ja, jeg vil [benefit]" / "Gi meg [value]"

Examples:
- "Ja, vis meg biler i nærheten"
- "Beregn min potensielle inntekt"
- "Start min gratis registrering"
```

### Formula 3: Question + Answer
```
[Pain point question]? [Solution CTA]

Examples:
- "Trenger bil til helgen? Finn tilgjengelige biler nå."
- "Står bilen ubrukt? Se hvor mye du kan tjene."
```

### Formula 4: Social Proof + Action
```
[Proof element] + [Action]

Examples:
- "Bli en av 8000+ fornøyde utleiere – registrer deg."
- "Tusenvis har allerede funnet sin leiebil – finn din."
```

### Formula 5: Urgency + Specificity
```
[Time element] + [Specific action]

Examples:
- "Book nå – helgens biler fylles opp"
- "Registrer deg i dag – start å tjene denne måneden"
```

## Part 8: Common CTA Mistakes

### Mistakes to Avoid

**1. Generic CTAs**
- ❌ "Learn more"
- ❌ "Click here"
- ❌ "Submit"
- ✅ "Find cars in Oslo"
- ✅ "Calculate your earnings"

**2. Mismatched Strength**
- ❌ Strong CTA on informational content ("BOOK NOW!" on an activities list)
- ❌ Soft CTA on transactional content ("Maybe explore options" on pricing page)

**3. Too Many CTAs**
- ❌ CTA after every section
- ❌ Multiple competing CTAs visible at once
- ✅ One contextual + one primary (max)

**4. Interruptive Placement**
- ❌ CTA in middle of explanation
- ❌ CTA before value is established
- ✅ CTA after value section
- ✅ CTA at natural pause points

**5. Missing Context**
- ❌ "Book now" (book what? where?)
- ✅ "Book your Oslo rental car now"

**6. Fake Urgency**
- ❌ "Limited time!" (when it's always available)
- ✅ "Weekend cars fill up fast" (authentic observation)
