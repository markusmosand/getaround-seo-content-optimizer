Please perform a daily standup review for the SEO Content Optimizer project:

## Step 1: Read Context
- Read `docs/TODO.md` for the current task list
- Read `docs/PROJECT_ANALYSIS.md` for project context (if needed)

## Step 2: Analyze Tasks
For each task in TODO.md, determine:
- Is it blocked? (check dependencies)
- Is it ready to work on?
- Can I (AI) complete it independently?

## Step 3: Generate Report

Provide a summary in this format:

### Today's Date: [DATE]

### 🎯 Recommended Focus
List 2-3 tasks that should be prioritized today, with reasoning.

### 🤖 Tasks I Can Complete Independently
List tasks marked with 🤖 that are not blocked.
For each, briefly explain what I would do.

### 🤝 Tasks Needing Collaboration
List tasks marked with 🤝 that are ready to work on.
For each, explain what input I need from you.

### 🚫 Blocked Tasks
List tasks marked with [!] and what's blocking them.

### ❓ Questions
Any clarifications needed before proceeding.

### 📝 Suggested Updates to TODO.md
If I notice any tasks that should be added, removed, or re-prioritized.

---

After generating the report, ask: "Would you like me to start on any of the AI-solo tasks?"
